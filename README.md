# SEIS732_Project
### Cally Minner
### SEIS 732, Fall 2026
Graduate project looking at book and literary trends to help an indie publishing house make informed decisions about book acquisitions.

The project carries one approved business need and dataset through design, implementation, reliability, quality, governed access, documentation, and delivery.


## Project Milestones

P0: Need, Audience, Dataset & Feasibility

P1: Grain, Model, History & Pipeline Plan

P2: Working Ingestion, Curation & Acceptance Checks

P3: Serving, Reliability, Quality & Lineage

P4: Access, Data Product, Documentation & Defense
